Middle/Senior Software Engineer (Frontend)

  • Full-time

Company Description

Devexperts works with respected financial institutions, delivering products and tailor-made solutions for retail and brokerage houses, exchanges, and buy-side firms. The company focuses on trading platforms and brokerage automation, complex software development projects, market data products, and IT consulting services. 

Job Description

We are looking for a Middle/Senior Software Engineer (Frontend) to work at Devexperts. We're building projects of different complexity – from chrome extensions to full-blown capital markets trading applications.
 

Technology stack includes, but is not limited to: TypeScript / React / various CSS libraries and A11y components. Backend includes Python Django and Golang.
 

Claude Code experience is a bonus.
 

We expect the Software Engineer to:
 

  • Be a team-player, collaborate efficiently, give timely answers and updates
  • Be able to understand the business value and set correct priorities
  • Have an ability to take ownership of codebase and tasks up to completion
  • Participate in daily meetings, perform core reviews and follow company standards
  • Create applications with quality in mind

Qualifications

    Must-have skills: 
     

    • Deep knowledge of JS core,
    • TypeScript and React hands-on experience,
    • Proficiency in HTML / CSS, including advanced practices (semantic HTML and Accessibility),
    • Understanding of how modern Web works (HTTP, WebSockets, Cookies),
    • English – spoken and written.
       

    Nice-to-have skills: 
     

    • Claude Code or any other agentic AI experience
    • Unit and end-2-end testing (Jest / Cypress / Playwright),
    • Web performance analysis (DevTools profiling / Web Vitals),
    • Experience or understanding of fp-ts library,
    • Experience with building WCAG a11y components.
